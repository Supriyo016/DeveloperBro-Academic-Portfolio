This month I settled a question I'd been putting off: which numbers should a dissertation on Alzheimer's classification actually report? I built a small invented example to make the answer concrete.

## An invented confusion matrix

Suppose a test set of 1,000 slices that looks more like a real clinic than a balanced dataset: mostly healthy, few moderate cases. Rows are the true class, columns the prediction. **These numbers are made up for illustration.**

| True ↓ / Predicted → | Mild | Moderate | Non | Very mild | Total |
| --- | --- | --- | --- | --- | --- |
| Mild | **180** | 0 | 10 | 10 | 200 |
| Moderate | 0 | **20** | 0 | 0 | 20 |
| Non-demented | 5 | 0 | **560** | 35 | 600 |
| Very mild | 10 | 0 | 90 | **80** | 180 |

Accuracy is $(180 + 20 + 560 + 80) / 1000 = 84.0\%$. That sounds fine, until you look at the last row: 90 of 180 very mild cases are called healthy. The class where early detection matters most has a recall of 44%.

## The per-class view

For class $c$, precision asks "when the model says $c$, how often is it right?" and recall asks "of all true $c$ cases, how many did it find?"

$$
\text{precision}_c = \frac{TP_c}{TP_c + FP_c}, \qquad
\text{recall}_c = \frac{TP_c}{TP_c + FN_c}, \qquad
F1_c = \frac{2 \cdot \text{precision}_c \cdot \text{recall}_c}{\text{precision}_c + \text{recall}_c}
$$

## Averaging across classes

| Summary | Value | What it weights |
| --- | --- | --- |
| Accuracy | 0.840 | Every image equally, so large classes dominate |
| Weighted F1 | 0.830 | Each class by its size |
| Macro F1 | 0.831 | Every class equally |
| Balanced accuracy (macro recall) | 0.819 | Every class's recall equally |
| Always predict "Non-demented" | 0.600 | The baseline any model must beat |

The last row is the one people forget. On this test set, a model that never looks at the image scores 60%. Any accuracy figure should be read against that floor.

## AUC, and what it does not tell you

The ROC curve plots true positive rate against false positive rate as the decision threshold moves, and its area (AUC) measures how well the model ranks positives above negatives. For four classes, I'll compute it one-versus-rest and average it.

AUC is threshold-free, which is both its strength and its weakness. A model can rank cases well, with a high AUC, and still make poor decisions at the threshold actually used. AUC also tends to look high when one class is easy.

## What I'll report

1. **Macro F1 and balanced accuracy** as the headline, so small classes count.
2. **Per-class precision, recall and F1**, always, with the confusion matrix.
3. **Accuracy beside the majority-class baseline**, never alone.
4. **Macro one-versus-rest AUC** as a secondary, ranking-quality figure.

<Callout type="key">
In a screening setting, a false "healthy" on a very mild case is the expensive error. A single summary number should never be allowed to hide which class is paying for it.
</Callout>
